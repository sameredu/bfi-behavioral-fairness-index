# Infrastructure-Aware Behavioral Fairness Theory (IABFT) — Behavioral Fairness Index (BFI)

Reference implementation and full reproduction code for the paper on the Behavioral Fairness Index
(Samer Yaghi, UCAS / IUG; Aiman A. AbuSamra, IUG).

```
BFI_i = alpha * P_i + beta * R_i + gamma * (1 - D_hat_i),   alpha, beta, gamma > 0,  alpha + beta + gamma = 1
```

`P` is rule-based disruption evidence, `R` is recovery (completion at the learner's next session of the
same kind), and `D_hat` is the normalized divergence from the learner's historical Golden Profile.
Theorem T0 shows that Axioms A1–A6 (A6 = evidence-mixture consistency) hold **if and only if** the
functional has this form.

## Version 2.0.0 — what changed and why

Version 1 contained a placeholder analysis (`R = 1 − P`) that could not reproduce the numbers in the
first manuscript. Version 2 replaces it with the pipeline the revised paper describes. Every
empirical number, table and figure in the paper is now generated by `src/run_all.py`.

| Component | v1 | v2 |
|---|---|---|
| `P` | unanswered ratio, described in the paper as a Random Forest output | noisy-OR of weighted unanswered share, entry latency (≥ 30 min = 1) and short-session flag |
| `R` | `1 − P` placeholder | completion at the learner's next session of the same kind; 0.5 when no later session exists |
| `D_hat` | `|u − mean(u)|` | Euclidean distance to an EMA Golden Profile (λ = 0.5) over (time-use ratio, ended-at-close, latency); cold start = population mean |
| Noise claim | `max |ΔBFI| ≤ 0.017` | exact flip probability Φ(−ρ / (σ‖w‖₂)) (Theorem T5) |
| Supplementary exams | single sitting assumed | two sittings (13 Apr, 11 May 2026) handled separately |

## Repository structure

```
src/
  load.py            # reads the 7 Zenodo files -> one row per session (675)
  pipeline.py        # features, P, R, D_hat, BFI, tiers
  analyze.py         # tiers, entropies, noise stability, Wilson CI, weight sensitivity
  validity.py        # discriminant validity, low-score criterion, AUCs
  validity2.py       # bootstrap CIs, baselines, tier composition
  run_all.py         # runs everything -> ./results/
  bfi.py             # stand-alone BFI utilities (v1, kept for the synthetic demo)
simulation/run_simulation.py   # synthetic check of T1–T4
figures/
  make_figure1_pipeline.py
  make_figure2_surface.py
  make_figures_3_4_results.py  # Figures 3 and 4 from real data
```

## Reproduce

```bash
pip install -r requirements.txt
# download the seven .xlsx files from https://doi.org/10.5281/zenodo.20366538 into ./data/
IABFT_DATA=./data python src/run_all.py      # writes results/*.json, *.csv, Figure3, Figure4
python figures/make_figure1_pipeline.py
python figures/make_figure2_surface.py
```

## Data

Dataset (CC BY 4.0): Yaghi, S., & AbuSamra, A. A. (2026). *Web Databases — Anonymized Moodle Examination
Dataset for Fairness-Aware Learning Analytics*. Zenodo. https://doi.org/10.5281/zenodo.20366538.
It contains Moodle quiz attempt reports only (timestamps, durations, per-item responses and scores).
No network telemetry or device data were collected, so disruption labels are behavioral, not
connectivity-verified.
